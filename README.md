# ZigZag Ball 3D 🏀
ZigZag Ball is a sleek, addictive 3D platformer designed for Android. The objective is simple: keep the ball on the path. As the platform generates and turns, you must react quickly to change direction and prevent the ball from falling into the void.

# 🎮 Gameplay Features
Physics-Driven Movement: Smooth, momentum-based ball physics that reward precise timing and quick reflexes.

Infinite ZigZag Path: A procedurally generated environment that keeps the challenge fresh every time you play.

High Score System: An integrated scoring mechanic that tracks your best runs, pushing you to beat your previous record.

One-Tap Controls: Simple, intuitive touch controls—perfect for mobile gaming on the go.

Minimalist 3D Design: Clean visuals and smooth camera follow logic for an immersive experience.

# 🛠️ Technical Specifications
Engine: Unity 2022.3.46f1 (LTS)

Platform: Android

Language: C#
